# DTC Growth Academy — Operator Labs

A free static collection of advanced DTC commercial decision simulators, powered by native HTML, CSS and JavaScript.

## Labs
- Day 01 — Unit economics, VAT, refunds, CAC and contribution
- Day 16 — Creator video quote underwriting and break-even impressions
- Day 20 — Affiliate commissions, incrementality and retained contribution

## Publish with GitHub Pages
Go to **Settings → Pages → Build and deployment**. Select **Deploy from a branch**, then select **main** and **/(root)**. Save. GitHub will publish the root `index.html` at the repository's Pages URL.

## Privacy and data quality
- All examples are hypothetical and synthetic.
- Do not commit confidential business data, customer records, real private financials, credentials, or non-public URLs.
- User-entered slider state stays in the local browser via localStorage; exports stay on the user's device.
- The app makes no analytics or backend requests.
- Estimates and attributed conversions should not be represented as causal incremental results.

## Stack
Static HTML/CSS/JS; no build or package manager, no dependency installation, no sign-in, and no database.
